# 深国转 × FDE 合作

本仓库整理 **国家知识产权运营（深圳河套）国际转化试点平台（深国转）** 与 **前沿部署工程师（FDE, Forward Deployed Engineer）** 协作落地的背景、目标与试点模块，供河套园区及合作方内部对齐使用。

## 背景速览

| 主体 | 说明 |
| --- | --- |
| **深国转** | 国家知识产权局授权，香港城市大学与深圳市共建的河套国际知识产权与科技成果转化运营平台，提供交易、结算、鉴证及跨境转化等服务。 |
| **FDE** | 驻场式混合角色（工程 + 业务 + 交付），将通用 AI/数据能力按客户语境定制并推动上线，典型用于 Agent 与复杂政企场景的「最后一公里」。 |

二者结合的方向：以深国转的平台能力（知识产权库、交易鉴证、深港协同）为底座，以 FDE 驻场交付把「转化与运营」落到具体企业与机构现场。
