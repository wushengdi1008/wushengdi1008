# 深国转 × FDE 合作展示页

这是一个零依赖静态页面，用于展示“深国转”和 FDE 的合作定位、重点方向和推进机制。

## 文件说明

- `index.html`：合作展示页主体内容。
- `styles.css`：页面布局、配色和响应式样式。

## 本地预览

在仓库根目录运行：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 内容维护

页面文案使用较稳健的合作框架表述，避免写入未经确认的具体成果、数据或承诺。后续可以根据真实项目资料补充合作案例、联系人、活动信息和正式品牌资产。
