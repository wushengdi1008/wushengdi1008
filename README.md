# 深国转与 FDE 合作方案

本仓库用于沉淀“深国转”和 FDE 团队的合作框架、执行计划与后续交付材料。由于当前尚未提供双方主体全称、正式合作协议或公开公告，以下内容采用合作方案模板写法，后续可根据正式材料继续补充。

## 合作定位

FDE 通常指 Forward Deployed Engineer，即前线部署工程师。该模式强调工程团队深入业务现场，与业务、运营和管理团队共同识别真实问题，并通过快速原型、数据分析和系统集成推动方案落地。

深国转与 FDE 的合作可聚焦于以下目标：

- 梳理深国转现有业务流程、数据资产和系统边界。
- 识别可通过数字化、智能化或自动化提升效率的高价值场景。
- 以小步快跑方式完成原型验证、试点部署和效果复盘。
- 将试点中的共性能力沉淀为可复用工具、流程和产品模块。

## 建议合作场景

1. **业务流程诊断**：围绕项目登记、审核流转、资源匹配、成果展示和后续跟踪等环节开展现场调研。
2. **数据治理与分析**：梳理业务数据口径，建立关键指标看板，支持管理决策和项目运营。
3. **智能助手应用**：面向内部人员或服务对象提供政策问答、材料初审、项目推荐和知识检索能力。
4. **系统集成优化**：打通存量系统、表单、文档和审批链路，减少重复录入和人工搬运。
5. **试点成果复用**：将经过验证的能力封装为标准化组件，支持后续在更多业务线复制。

## 推进机制

| 阶段 | 重点工作 | 输出物 |
| --- | --- | --- |
| 需求澄清 | 明确合作目标、参与角色、业务边界和数据条件 | 合作需求清单 |
| 现场调研 | 访谈业务人员，梳理流程、系统和痛点 | 场景诊断报告 |
| 原型验证 | 选择 1-2 个高价值场景快速实现可用原型 | 原型系统与测试记录 |
| 试点部署 | 在真实业务流程中验证效果，收集反馈 | 试点复盘报告 |
| 规模推广 | 抽象共性能力，形成可复用方案 | 标准化交付包 |

## 协作分工

- **深国转**：提供业务场景、流程资料、测试环境、关键用户反馈和验收标准。
- **FDE 团队**：负责现场调研、技术方案设计、原型开发、系统联调和持续迭代。
- **联合工作组**：定期评审需求优先级、交付进度、数据安全要求和试点效果。

## 风险与约束

- 需提前明确数据权限、脱敏规则和系统访问边界。
- 试点范围应保持聚焦，优先选择价值清晰且可验证的场景。
- 技术方案需兼顾现有系统约束，避免引入过重的改造成本。
- 所有对外表述应以双方正式确认的合作文件为准。

## 待确认事项

- “深国转”的正式全称及合作主体。
- FDE 团队所属机构、服务范围和交付边界。
- 首批试点业务场景及优先级。
- 数据、安全、合规和验收要求。
- 是否需要形成对外发布稿、内部汇报材料或项目计划书。
