# 深国转与 FDE 合作方案

## 1. 合作定位

**深国转**（国家知识产权运营〔深圳河套〕国际转化试点平台）面向粤港澳大湾区及国际市场，集聚知识产权与科技成果资源，提供一站式交易、结算与鉴证，并依托港城大及河套区位推动跨境转化。

**FDE**（Forward Deployed Engineer，前沿部署工程师）强调工程师深入客户现场：理解业务流程与数据现状，快速集成系统、搭建可运行方案，并将现场经验反哺产品与平台能力。在 AI Agent 与企业数智化场景中，FDE 被广泛用于把「通用模型/平台」打磨为可交付的业务结果。

**合作命题**：深国转提供「知产与成果运营的制度与平台能力」，FDE 提供「按场景驻场交付与迭代」的方法论与人才机制，共同缩短从「专利/成果入库」到「企业侧可运营、可度量转化」的路径。

## 2. 合作目标

1. **转化提速**：针对制造业出海、深港双向转化等典型场景，以 FDE 小队驻场梳理需求，对接深国转交易与鉴证流程。
2. **服务产品化**：将驻场项目中可复用的工作流（尽调清单、估值辅助、合规材料包、跨境结算节点）沉淀为深国转平台的标准模块。
3. **生态协同**：联动河套园区算力、金融与科研服务（如「河套人工智能算力通」、惠港金融等），为 IP 运营与 AI 落地提供一体化环境。
4. **人才与标准**：探索「知识产权运营 + 前沿部署工程」复合人才培养与岗位标准，服务河套知识产权「36条」相关举措。

## 3. 协作模块（建议试点）

### 3.1 企业侧 IP 运营 Agent 驻场

- **场景**：制造企业、科研机构、出海企业知识产权布局与转化。
- **FDE 职责**：梳理专利族/技术栈与业务 KPI，搭建检索、比对、报告生成等 Agent 工作流，对接企业 ERP/PLM/法务系统（在授权范围内）。
- **深国转职责**：提供权威 IP 数据与交易、鉴证、跨境转化通道；对输出材料进行平台侧合规与流程背书。

### 3.2 跨境转化「碎石路 → 高速路」

沿用 FDE 方法论中的两阶段交付：

| 阶段 | 周期（参考） | 交付物 |
| --- | --- | --- |
| 碎石路（Gravel road） | 约 8–12 周 | 单客户最小可行转化链路：标的筛选、尽调、估值草案、交易/许可路径建议 |
| 高速路（Paved road） | 持续迭代 | 将碎石路中验证的步骤固化为深国转平台模板与自助服务 |

### 3.3 深港协同项目专班

- 面向港城大及河套入驻团队，设立「深国转 + FDE」联合专班。
- 输出：深港知识产权论坛/路演项目的标准交付包（中英文材料、鉴证节点 checklist、后续跟投/产业化对接清单）。

### 3.4 反馈闭环（Frontier sensing）

- FDE 将驻场中发现的共性障碍（数据接口、合规疑问、行业估值模型缺口）按周同步至深国转产品与政策对接窗口。
- 深国转将平台规则与政策更新反向注入 FDE  playbook，避免重复踩坑。

## 4. 组织与分工（建议）

| 角色 | 深国转侧 | FDE 侧 |
| --- | --- | --- |
| 平台与合规 | 交易规则、鉴证、跨境流程、数据授权 | 遵守平台 API 与审计要求 |
| 现场交付 | 派驻联络人、专家库 | 驻场工程师、解决方案架构 |
| 产品沉淀 | 平台功能立项与发布 | 提交可复用组件与评估用例 |
| 生态 | 政府、港城大、金融机构对接 | 企业/园区客户拓展与实施 |

## 5. 阶段计划（示意）

| 阶段 | 重点 | 成功标志 |
| --- | --- | --- |
| **Phase 0 — 对齐** | 明确试点行业（如电子信息、生物医药、先进制造）与 2–3 家种子客户 | 联合工作组、数据与合规边界书面确认 |
| **Phase 1 — 碎石路试点** | 完成 1–2 个端到端驻场项目 | 可演示的转化链路 + 客户验收纪要 |
| **Phase 2 — 平台固化** | 上线模板化服务包与自助入口 | 平台侧复用率、平均交付周期下降 |
| **Phase 3 — 规模化** | 复制至更多河套/大湾区客户与深港活动 | 稳定 FDE 梯队与可度量 ROI |

## 6. 风险与原则

- **合规优先**：涉跨境数据、商业秘密与出口管制场景，须先过深国转合规与法务评审再驻场开发。
- **避免纯人力外包**：FDE 项目须绑定平台能力沉淀指标，防止沦为不可规模化的定制开发。
- **成果归属**：专利/技术成果权属、许可条款以深国转及各方既有协议为准；Agent 与软件交付物须在合同中约定 IP 与开源边界。
